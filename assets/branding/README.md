# Application icon

- `app-icon.png` is the 1024 × 1024 project artwork with transparent outer corners.
- `app-icon.ico` contains Windows icon frames from 16 × 16 through 256 × 256.
- The character is intentionally unnamed; user-defined NPC names and personas are never baked into the application branding.
- The original artwork was generated from a project-specific prompt and then locally resized, alpha-masked, and packaged as a multi-resolution Windows icon.
