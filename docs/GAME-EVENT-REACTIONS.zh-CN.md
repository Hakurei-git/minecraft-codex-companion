# 游戏广播与事件回应

开启“自由聊天与事件回应”后，AI 会回应当前绑定玩家的死亡、重生、进度、目标和挑战成就。沿用当前自由聊天选择的 AI 和人格：反重力继续使用原绑定会话，“跟随 Codex”或其他活动提供方使用无工具聊天回合；多代理模式由 Codex 给出一次回应。

只关注配置中的玩家。其他玩家的广播、普通系统提示、动作栏、NPC 自己的聊天不会触发。进度和成就从游戏的结构化广播中识别；若服务器关闭进度广播，或模组只发送自定义纯文本通知，这些成就不会被转发。玩家死亡另有本地生命状态检测，死亡广播缺失时仍可通知。

同一事件只回应一次；1.5 秒内连续通知会合并，两个回应批次至少间隔 8 秒，每批最多 8 条。临时断线时短暂保存通知，超过 60 秒的事件丢弃，离开世界后清空。死亡和随后的重生可合并为一次回应。

事件独立于玩家聊天指令，不进入游戏任务解析。Codex 事件回合禁用工具；反重力通过一次性、只允许 `chat` 的决策提交回复，不能将该通知转换成控制或建造等任务。关闭自由聊天会同时关闭事件回应。

新功能包含游戏模组变更，更新后需要完全退出并重新启动 Minecraft，单独重连控制服务不会加载新模组。检测与去重逻辑同时用于 Forge 1.20.1 和 NeoForge 1.21.1；实际游戏验收状态将在发布检查记录中注明。
