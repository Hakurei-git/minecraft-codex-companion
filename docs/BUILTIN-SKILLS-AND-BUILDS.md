# 离线 Skills、MCP 与安全建筑模板

本目录描述 Minecraft Codex Companion 自带的**数据型**技能和建筑模板。它们不包含 JavaScript、Shell、PowerShell、可执行文件或动态下载逻辑。

## 信任与隐私边界

- 来源：`built-in`，作者为 `Minecraft Codex Companion contributors`。
- 内容许可：`CC0-1.0`（仅适用于本项目内置的技能定义与建筑模板数据）。
- 网络权限：`none`；执行技能不联网，也不读取 URL。
- 文件权限：`none`；技能参数不能包含本地绝对路径。
- 系统命令：`false`。
- 命令方块：`false`。
- 方块实体 NBT：`false`。
- 每项技能和建筑模板在运行时都返回其 SHA-256 内容哈希。
- API/MCP 输出统一经过敏感字段、密钥、令牌及本地路径脱敏。

外部 Skill 不会自动取得信任。它必须提供 HTTPS 来源、作者和许可，先通过静态检查，再由本地用户明确批准；内容改变后 SHA-256 改变，原批准自动失效。任何包含密钥、令牌、本地绝对路径、系统命令或未声明网络目标的内容都会被拒绝。

## 内置建筑模板

| 模板 | 对应 Skill | 说明 |
| --- | --- | --- |
| 安全基础刷石机（自动放置流体） | `build.cobblestone-generator` | 自动补齐 57 个圆石并建造无命令、无 NBT 的主体，再通过 Forge 标准右键交互放置水源和岩浆源。生存模式需要 NPC 背包中各有一个对应桶；创造模式提供临时资源且不消耗物品。模板不再要求不可自动取得的黑曜石。 |
| 七格基础住宅 | `build.basic-shelter` | 生存模式采集 39 个橡木原木、8 个圆石和 3 个沙，并按真实配方准备 116 木板、49 半砖和 3 玻璃；创造模式跳过材料准备。 |
| 九格安全农田 | `build.crop-farm` | 生存模式采集 12 个橡木原木和 42 个泥土，制作框架与木锄；建成后在准备好的泥土地内执行指定作物的农务循环。种子耗尽会进入同任务采集/制作前置链，不会扩张到周围草地或误报成功；灌溉仍需显式补水。 |
| 分类仓库 | `build.storage-room` | 生存模式采集 31 个橡木原木和 35 个圆石，制作足量木板、半砖和 6 个木桶；建成后整理家园仓库。 |
| 石砖小屋 | `build.stone-cottage` | 七格石砖、玻璃和半砖结构；缺料时复用通用补料链。 |
| 九格动物围栏 | `build.animal-pen` | 普通栅栏与栅栏门，不生成、传送或修改生物。 |
| 木石瞭望塔 | `build.watchtower` | 木石支柱、双层平台、内部梯子与顶部护栏。 |
| 基础黑暗刷怪塔（无刷怪笼） | `build.mob-farm` | 普通圆石黑暗平台、23 格坠落井和收集开口；不生成、不获取也不放置刷怪笼。 |
| 规则自动树场 | `build.tree-farm` | 带八个泥土种植位的规则基座；树苗种类和后续砍伐由农务/采集任务指定。 |

模板使用稳定 ID，并在服务启动时注册为 `builtIn=true`、`confirmed=true`。建筑 Skill 使用 `placement="companion"`，接令时会锁定 NPC 旁边的建筑原点；即使 NPC 随后远程采集、战斗插队或控制服务重启，建造也会回到这个原点。原点只保存在本机任务日志中，不修改原模板、不包含本地目录或凭据，也不会上传。

材料准备步骤带有 `whenMaterialMode="survival"` 条件。创造模式只执行建造与后续生活步骤；生存模式会使用整树/矿物远程搜索、真实制作和真实烧炼，缺少无法自然取得的物品时明确报告失败。建筑原点在材料准备前固定，因此远距离搜索不会把房屋建到资源点。

已确认建筑还带有游戏侧的通用补料状态机。每批材料用完时，它会在**同一个 build 任务**中按“家中仓库 → 真实制作 → 熔炉烧炼 → 安全直采”推进；上游可以递归形成原木/木板/木构件、圆石/石头/石砖、黏土球/黏土块、沙/玻璃/玻璃板、煤/木棍/火把、原矿/金属锭以及工作台/熔炉链。补料、远程采集、护主暂停、倒地和保存退出都保留原建筑索引与材料目标，完成后回到锁定原点继续。临时工作站会避开蓝图的水平占地；熔炼只使用该材料目标自己放置并在检查点中记录的熔炉，炉内输入、在制产物和已收取产物共同参与缺口计算，不会拿取玩家熔炉内容或重复采集已装炉原料。水/岩浆桶、危险或不可再生材料不会盲采，只能使用背包或家中仓库已有物品。未知模组方块只允许使用本机世界中真实存在的制作/熔炼配方，且其最终原料仍必须落入允许采集或已有库存的安全边界。

游戏聊天输入“建造”会显示 1-9 选项；菜单在本机保存三分钟，可回复数字、中文数字或建筑名称。“继续建造”不会重新分配模板，而是重试最近一次失败的同一任务 ID。游戏侧单独保存建筑原点、`buildIndex`、目标坐标、材料子链与失败原因；普通占位方块经 Forge 标准破坏事件清理，外部领地保护可以拒绝该动作。容器、任何方块实体、不可破坏方块、传送门、命令/结构方块和刷怪笼均不会自动清理。

所有导入方式（JSON、Schem、Litematic、PNG）和直接预览 API 都经过同一个 `build-safety` 安全门。以下内容被拒绝：命令方块、连锁/循环命令方块、结构方块、拼图方块、刷怪笼、末地传送门/折跃门，以及命令式或自动执行属性。

## 制作与装备 Skills

- `life.craft-and-place-bed`：先检查背包和家中箱子；缺木板时制作或砍树，缺羊毛时扩大范围寻找未命名成年白羊；没有可用剪刀时补铁、烧炼并制作剪刀；床完成后返回玩家复活点，在有实体支撑且头脚两格可替换的位置通过真实右键交互放置并验证。

- `craft.starter-tools`：工作台、木镐、石镐、石斧、熔炉。
- `craft.iron-equipment`：烧铁并制作铁剑、铁镐、盾牌与整套铁甲。
- `craft.building-materials`：按参数制作木板、半砖和箱子。

这些 Skill 只提交游戏内 `craft`/`smelt` 任务。制作器会使用当前世界的真实配方逐级加工 NPC 已有的中间材料（例如原木 -> 木板 -> 木棍），但不提供原始资源、不绕过配方，也不执行系统命令。

## 远征 Skill

- `life.expedition-and-deliver`：缺少必要矿具时先用真实配方补齐，然后持续扩大资源搜索范围；目标达成后回到指定玩家身边物理交付。护主会临时暂停远征，危险解除后恢复原进度。
- 开启作弊时，只允许在超过召回距离或寻路恢复条件成立时传送到安全位置；未开启作弊时全程走路。Skill 本身不调用命令、不读取文件、不联网。

## 寻食与畜牧 Skills

- 游戏聊天输入“去找些食物”会直接分配 `provision-food`，默认在 NPC 背包保留 8 份口粮。“给我找些食物”与“找些食物给我”会返回玩家身边物理交付；“找些食物放到家里箱子”会将目标数量存入家/复活点附近仓库。任务扩大范围寻找成熟胡萝卜、马铃薯、甜菜根、西瓜和甜浆果；普通成熟作物收获后会重新种植。只有背包自留模式会把家中现有口粮取出来补足，交付和入库模式不会先从目标箱子取出再放回。
- `source=auto` 会在采集不足时安全猎取成年猪、牛或羊，但不猎杀幼崽、命名、驯服、已拴住或家附近动物，并为同类保留至少两只成年繁殖种群。`source=forage` 只采集植物，`source=hunt` 强制使用安全猎食规则。腐肉、蜘蛛眼、毒马铃薯、河豚、紫颂果和金苹果不计入普通口粮储备。
- 生牛肉、猪排、羊肉、鸡肉、兔肉、鳕鱼、鲑鱼和马铃薯会优先通过真实熔炉烹饪；缺熔炉或燃料时使用真实制作/采集前置链。搜索位置、动物 UUID、烹饪阶段与失败目标写入本机任务检查点，护主、保存退出或控制服务重启后继续原任务。
- `life.establish-ranch`：先执行 `build.animal-pen`，再检查家中拴绳或用真实配方制作，扩大范围寻找成年猪牛羊并逐只步行牵回。NPC 会在每次外出和返回时真实开关围栏门；牵引期间不单独传送 NPC，护主、离线或倒地插队时释放拴绳并保留已完成数量。
- `ranch` 还支持围栏内按物种食物进行繁殖，以及在保留指定成年种群后淘汰超额牲畜。它不会修改玩家已有家畜、凭空生成动物或调用命令。

## 双龙模组 Skills

仅覆盖当前整合包中的两个龙模组：

- `dragon.bookofdragons-field-kit`：`bookofdragons` 的驯龙哨、维京铁砧、防火鳞甲、响尾杖。
- `dragon.egg-care`：照料当前双龙整合包中的目标龙蛋。
- `dragon.heal-and-follow`：观察、治疗目标龙并恢复跟随。
- `dragon.saintsdragons-care-kit`：`saintsdragons` 的龙刷、丰盛龙餐、龙族图鉴，并观察/喂养目标龙。
- `dragon.saintsdragons-binder`：仅允许当前模组配方中七种 binder ID 的枚举参数。

上述物品 ID 由本地模组 JAR 的 `assets/*/models/item` 与 `data/*/recipes` 清单离线核对；检查过程中没有上传模组、存档、目录、账号或配置。

## MCP 使用

1. 调用 `mc_list_skills` 查看 Skill 参数、来源、许可、SHA-256、安全状态与工具权限。
2. 调用 `mc_list_build_plans` 查看建筑方块、材料清单、来源、许可、SHA-256 和完整零权限清单。
3. 调用 `mc_assign_task`，任务类型使用 `macro`，并填入 `skillId` 与参数。
4. 调用 `mc_get_task` 查看宏的顺序执行进度。

内置建筑已经过本地安全审核，因此可由宏直接使用；用户导入的建筑仍必须预览并调用 `mc_confirm_build` 明确确认。
